# FluxLoom

FluxLoom enables real-time, high-performance event-driven processing and data streaming across multiple system processors.

FluxLoom is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/FluxLoom.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

FluxLoom is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
